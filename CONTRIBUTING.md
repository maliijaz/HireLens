# Contributing

Thanks for considering a contribution to AI Hiring Assistant.

## Local setup

```bash
pip install -r requirements.txt
cp .env.example .env
# add your Groq API key to .env (free tier: https://console.groq.com/keys)
streamlit run app.py
```

## Making changes

1. Fork the repo and create a branch off `main`.
2. Keep changes focused — one logical change per pull request.
3. Test your change by running the app locally against the sample JD/resumes in the repo root.
4. Open a pull request describing what changed and why.

## Reporting bugs / suggesting features

Open a GitHub issue with steps to reproduce (for bugs) or a clear description of the use case (for features).

## Code of conduct

Be respectful and constructive. Harassment or abusive behavior will not be tolerated.
